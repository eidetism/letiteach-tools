# LETIteach Tools

Набор вспомогательных инструментов для платформы LETIteach:

- загрузка доступных пользователю видеоблоков курса физики в MP4;
- преобразование MP4 в MP3;
- навигация по встроенным вопросам и ускоренный просмотр через Tampermonkey.

Сейчас загрузчик настроен конкретно на курс физики. Репозиторий при этом не ограничен одним курсом: сюда можно добавлять отдельные инструменты для других разделов LETIteach.

## Ограничения

- Интерактивные вопросы между видео не входят в HLS-плейлисты и не скачиваются.
- Идентификаторы подтем нужно указать явно, например `1_2,1_3,1_4`.
- Некоторые номера могут отсутствовать или иметь не все варианты качества.
- Используйте скрипты только для материалов, к которым у вас есть законный доступ.

## Зависимости

Нужны `yt-dlp` и `ffmpeg`.

### Windows

```powershell
winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg
```

### macOS

```bash
brew install yt-dlp ffmpeg
```

### Arch Linux

```bash
sudo pacman -S yt-dlp ffmpeg
```

### Ubuntu и Debian

```bash
sudo apt update
sudo apt install yt-dlp ffmpeg
```

Версия `yt-dlp` в старых выпусках Ubuntu может быть устаревшей. В таком случае используйте `pipx install yt-dlp`.

## Windows

Скачать несколько подтем в 720p:

```powershell
.\download-letiteach.ps1 -LectureIds 1_2,1_3,1_4 -Quality 720p
```

Если PowerShell запрещает запуск локального скрипта:

```powershell
powershell -ExecutionPolicy Bypass -File .\download-letiteach.ps1 -LectureIds 1_2,1_3,1_4 -Quality 720p
```

## Linux и macOS

Сначала разрешите запуск:

```bash
chmod +x download-letiteach.sh
```

Затем скачайте нужные подтемы:

```bash
./download-letiteach.sh --ids 1_2,1_3,1_4 --quality 720p
```

## Список подтем в файле

Создайте `lectures.txt`:

```text
# Тема 1
1_2
1_3
1_4

# Тема 2
2_1
2_2
```

Windows:

```powershell
.\download-letiteach.ps1 -ListFile .\lectures.txt -Quality 720p
```

Linux и macOS:

```bash
./download-letiteach.sh --list-file ./lectures.txt --quality 720p
```

Строки, начинающиеся с `#`, и пустые строки игнорируются.

## Качество

Поддерживаются следующие значения:

| Значение | Результат |
| --- | --- |
| `best` | Лучший вариант из `master.m3u8` |
| `1080p` | Оригинальный поток `orig` |
| `720p` | Поток 1280x720, значение по умолчанию |
| `540p` | Поток 960x540 |

Пример выбора лучшего качества:

```bash
./download-letiteach.sh --ids 1_2 --quality best
```

## Как формируется идентификатор

Идентификатор повторяет структуру курса, но точка между номером темы и подтемы заменяется знаком подчёркивания:

| Структура в LETIteach | Идентификатор для скрипта |
| --- | --- |
| Тема 1, подтема 1.2 | `1_2` |
| Тема 1, подтема 1.3 | `1_3` |
| Тема 1, подтема 1.4 | `1_4` |
| Тема 2, подтема 2.1 | `2_1` |

Например, для последовательной загрузки подтем 1.2, 1.3 и 1.4 нужно передать `1_2,1_3,1_4`.

## Выходные файлы

По умолчанию видео сохраняются в каталог `letiteach-physics`:

```text
letiteach-physics/
├── 1_2.mp4
├── 1_3.mp4
└── 1_4.mp4
```

Другой каталог можно указать параметром `--output` или `-OutputDirectory`.

## Преобразование MP4 в MP3

Конвертеры обрабатывают все MP4-файлы из каталога `letiteach-physics` и сохраняют аудио в `letiteach-audio`. По умолчанию используется mono MP3 с битрейтом 96 кбит/с. Для лекций этого достаточно, а файлы получаются существенно меньше исходного видео.

Windows:

```powershell
.\convert-to-mp3.ps1
```

Linux и macOS:

```bash
chmod +x convert-to-mp3.sh
./convert-to-mp3.sh
```

Выбор другого битрейта и каталогов:

```powershell
.\convert-to-mp3.ps1 -InputDirectory .\videos -OutputDirectory .\audio -Bitrate 128k
```

```bash
./convert-to-mp3.sh --input ./videos --output ./audio --bitrate 128k
```

Уже существующие MP3-файлы пропускаются и не перезаписываются.

## Навигация по вопросам через Tampermonkey

Файл `letiteach-question-navigator.user.js` добавляет на страницу LETIteach панель для переключения между встроенными в видео вопросами. Плеер скрывается локально, а вопросы показываются по одному.

Скрипт намеренно не подделывает время просмотра и не отправляет на сервер принудительную отметку о завершении лекции.

Установка:

1. Установите расширение Tampermonkey для своего браузера.
2. Создайте новый пользовательский скрипт.
3. Замените его содержимое кодом из `letiteach-question-navigator.user.js`.
4. Сохраните скрипт и обновите страницу курса.

На странице курса постоянно отображается боковая панель:

- `Назад`;
- `Следующий вопрос`;
- `Просмотр ×8` для реального ускоренного воспроизведения видео;
- `Показать лекцию`.

`Показать лекцию` возвращает штатный интерфейс видео, но больше не удаляет боковую панель. Поэтому ускорение ×8 и навигация по вопросам остаются доступны до перехода со страницы курса.

Скрипт автоматически повторяет поиск видеоплеера и вопросов, когда LETIteach динамически загружает другой блок курса. Если текущий блок ещё не загрузился, панель показывает состояние `Ожидание видеоблока`.

Перед запуском ×8 скрипт выходит из принудительного режима показа вопросов и возвращает штатный видеоплеер. Это предотвращает конфликт, при котором LETIteach одновременно открывал вопрос и отменял вызов `video.play()` с ошибкой `AbortError`.

Кнопка ускоренного просмотра не изменяет `watch_times` вручную и не отправляет принудительный `completion: 1`. Засчитает ли LETIteach ускоренное воспроизведение как полный просмотр, зависит от серверных правил курса. Если встроенный вопрос поставит видео на паузу, ответьте на него и нажмите кнопку ×8 ещё раз.
